## Instalação e Configuração da biblioteca geolocator

acessa pub.dev

**Ler documetação da biblioteca a ser utilizada**

- geolocator

como usar:
1. instalar a biblioteca no projeto -> no terminal: flutter pub add geolocator

2. habilitar o uso do geolocator no AndroidManifest.xml (android/app/src/main).

3. usar a biblioteca
>obs: antes do primeiro uso do gps, é necessario habilitar o serviço de GPS pelo apk (fazer usando código)
